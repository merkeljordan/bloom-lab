Bloom at your board

Describe it. Choose the pieces. Then write RTL.

1The only file you edit

Level 1: flower_level1.sv  ·  Level 2: flower_level2.sv

Leave the top_level, tb_, and .xdc files alone. They are already done.

2Every change: save, simulate, build, program

Level 1Level 2
Simulation toptb_flower_level1tb_flower_level2
Board toptop_level1top_level2
Test should printLEVEL1 TESTBENCH PASSEDLEVEL2 TESTBENCH PASSED
  1. Save your file with Ctrl+S.
  2. Simulate. In Sources → Simulation Sources, right-click the simulation top → Set as Top. Then Run Simulation → Run Behavioral Simulation. Read the Tcl Console at the bottom for the PASSED line. Close the simulation when done.
  1. Build. In Design Sources, right-click the board top → Set as Top. Click Generate Bitstream and say yes to running the earlier steps. Wait for Bitstream Generation Completed.
  2. Program. Board plugged in and switched on. Open Hardware Manager → Open Target → Auto Connect → Program Device → Program. The green DONE light turns on.

3The board

SW0Water
SW1Sun
BTNCReset to seed (Level 2)
BTNUGrow again, if both switches are on (Level 2)
LD0–LD2Seed, sprout, bloom. Level 1 uses LD0 only.

4What you should see

Level 1: LD0 lights only when SW0 and SW1 are both up. Flip either one down and it turns off right away.

Level 2:

  1. Press BTNC. LD0: seed.
  2. Turn both switches on. LD1: sprout.
  3. Press BTNU. LD2: bloom. It stays there until reset.

5If something is wrong

  • Red error in Vivado: open the Messages tab and fix the first error. It gives the line number.
  • Test says FAILED: the line above it names the case. Compare it to the table on the slide.
  • Board doesn't match the test: did you save? Is the right board top set? Generate the bitstream and program again.
  • Level 2 jumps straight to bloom: your stage changes on every clock. Only move when grow is 1.
  • Level 2 does nothing: press BTNC first, then turn both switches on.
  • Hardware Manager can't find the board: check the power switch, then try another USB port or cable.

6Optional: the flower window

With the board programmed and plugged in, double-click BloomViz.exe, pick your board's port from the Board list, and press Connect. Not sure which port? It's the one that appears when you plug the board in.
