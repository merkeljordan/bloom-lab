# Bloom workshop slides

A 2-hour facilitator deck that follows the student lab manual. Open in a browser (needs internet once for Reveal.js, Mermaid, and fonts).

## Present

1. Open `slides/index.html` in Chrome, Edge, or Firefox.
2. **→** next step · **↓** more on Level 1 or Level 2 · **←** / **↑** back.
3. **Esc** shows the slide grid.

Print or PDF: open the same file with `?print-pdf` on the URL, then use the browser’s print dialog (Save as PDF, landscape).

## What is in the deck

What the flower is → what RTL means → the build steps → the board → Level 1 (vertical stack) → Level 2 (vertical stack) → visualizer → extras → debug → close.

Keep `docs/student-lab-manual.md` in front of students. These slides are for the projector, not a replacement for the handout.

## Offline

If the room has no network, host the CDN files locally or present from a machine that already cached them. The lab RTL does not depend on this deck.
